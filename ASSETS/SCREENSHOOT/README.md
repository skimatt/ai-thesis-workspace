# ASSETS/SCREENSHOOT - DIREKTORI BUKTI VISUAL SISTEM

Folder ini digunakan khusus untuk menampung gambar tangkapan layar (*screenshot*) asli dari sistem, aplikasi, antarmuka pengguna (UI), database, atau hasil pengujian lapangan yang disediakan oleh mahasiswa/peneliti.

## Ketentuan:
1. **User-Provided Material**: Screenshot harus berasal dari sistem nyata, bukan manipulasi visual AI atau mockup fiktif yang diklaim sebagai aplikasi berjalan.
2. **Penamaan Berkas**: Gunakan penamaan konsisten, contoh:
   - `gambar_3_1_form_login.png`
   - `gambar_4_1_dashboard_admin.png`
   - `gambar_4_2_hasil_perhitungan_wp.png`
3. **Penyajian di Dokumen**: Setiap screenshot yang dimasukkan ke naskah skripsi wajib diberi nomor gambar, judul/caption, dan diulas secara kontekstual di dalam teks naskah sesuai SOP Format.

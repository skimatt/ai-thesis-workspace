# AI_program - AREA KERJA INTERNAL AGENT

Folder ini khusus digunakan untuk kebutuhan teknis operasional AI Agent saat memproses berkas atau menjalankan analisis sementara.

## Subfolder:
- `scripts/` : Script otomasi, parsing docx, ekstraksi teks, atau pengujian lokal.
- `temp/`    : Berkas sementara, cache, intermediate conversion.
- `working/` : Draf kerja sementara yang sedang diedit sebelum masuk tahap final.
- `logs/`    : Catatan eksekusi, laporan QA sementara, atau log pemeriksaan tata bahasa.

## ATURAN KETAT:
1. Berkas di dalam folder ini **BUKAN** data penelitian resmi.
2. File di dalam folder ini **TIDAK BOLEH** dipindahkan langsung ke `OUTPUT/` tanpa melalui Quality Control.
3. Agen dilarang memperlakukan teks atau angka yang dihasilkan di folder ini sebagai bukti ilmiah yang terverifikasi (*anti circular reasoning*).

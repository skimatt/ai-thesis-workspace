# REPOSITORI DOKUMEN PDF LITERATUR ILMIAH

Direktori ini menyimpan seluruh berkas naskah utuh (PDF) referensi ilmiah yang digunakan dalam penulisan skripsi.

```text
REFERENSI/pdf/
├── belum_diverifikasi/  <- Kotak masuk (inbox) naskah yang baru diunduh dan belum dibaca utuh
├── jurnal/              <- Artikel jurnal ilmiah terakreditasi nasional (SINTA) & internasional (Scopus/WoS)
├── buku/                <- Buku teks referensi akademik resmi ber-ISBN
├── prosiding/           <- Makalah prosiding konferensi/seminar nasional & internasional
├── laporan_resmi/       <- Dokumen regulasi pemerintah, undang-undang, SK, dan standar industri (ISO/SNI)
└── skripsi_tesis/       <- Tugas akhir/skripsi pembanding dari repositori perguruan tinggi resmi
```

> [!IMPORTANT]
> **ATURAN INTEGRITAS AKADEMIK: NO SOURCE, NO CLAIM.**
> Seluruh naskah yang disimpan di sini wajib memiliki file fisik riil. Jangan pernah mengutip pernyataan ilmiah jika berkas aslinya belum dipindahkan ke kategori terverifikasi.
